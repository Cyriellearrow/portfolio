🔬 CCPNMR v3 to Cyana Convertor

Outil de conversion pour l'analyse de données RMN

📖 Vue d'ensemble

Le CCPNMR v3 to Cyana Convertor est un outil développé pour faciliter le travail des chercheurs en RMN (Résonance Magnétique Nucléaire). Il permet de convertir automatiquement les données issues du logiciel CCPNMR Analysis v3 vers un format compatible avec CYANA, évitant ainsi des heures de travail manuel fastidieux.

Python PyQt6 pandas GUI CSV

🎯 Contexte et problématique

Le problème

Dans le domaine de la recherche en biologie structurale, les scientifiques utilisent différents logiciels pour analyser leurs données RMN. Passer de CCPNMR Analysis v3 à CYANA nécessitait auparavant :

  • Une conversion manuelle des fichiers de données
  • Un reformatage fastidieux des listes de pics (plus de 500 lignes Excel)
  • Une vérification minutieuse pour éviter les erreurs
  • Plusieurs semaines, voire plusieurs mois, de travail répétitif par projet

La solution

J'ai développé un outil avec interface graphique qui automatise entièrement ce processus, permettant aux chercheurs de se concentrer sur l'analyse plutôt que sur la manipulation de fichiers.

💡 Impact : Réduction du temps de conversion de plusieurs heures à quelques secondes, tout en éliminant les risques d'erreurs de saisie manuelle.

⚙️ Fonctionnalités principales

  • Interface graphique intuitive — développée avec PyQt6 pour une utilisation simple et accessible
  • Conversion automatique — traitement des fichiers CCPNMR et génération automatique des fichiers CYANA
  • Gestion des données structurées — utilisation de pandas pour manipuler efficacement les données tabulaires
  • Export personnalisable — options de formatage selon les besoins spécifiques

🛠️ Technologies utilisées

Python 3.13

Langage principal du projet, choisi pour sa simplicité et sa puissance dans le traitement de données.

PyQt6 6.9.1

Framework pour l'interface graphique, permettant de créer une application desktop moderne et réactive.

Pandas 2.3.2

Manipulation de données complexes au format CSV.
