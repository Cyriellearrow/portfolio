🧙‍♀️ The Witch's Hunt

Jeu vidéo en pixel art réalisé avec Godot et C#

📖 Vue d'ensemble

The Witch's Hunt est un jeu vidéo en pixel art jouable en ligne sur itch.io. J'y ai participé au sein d'une équipe, en tant que programmeuse et artiste : j'ai programmé le comportement des citrouilles ennemies (IA) qui attaquent le personnage, créé le menu, intégré les sons, puis dessiné l'interface et une partie du pixel art.

Godot C# GitHub Pixel art UI
Captures d'écran du jeu à ajouter (dossier image/)

🧩 Mon rôle

  • Programmation — bot (IA) des citrouilles qui poursuivent et attaquent le personnage, menu principal et intégration des sons, en C# avec Godot
  • UI Art — création des éléments graphiques de l'interface (menus, boutons, éléments d'affichage)
  • Pixel art complémentaire — création de sprites et d'éléments visuels supplémentaires pour le jeu

🛠️ Technologies utilisées

Godot

Moteur de jeu utilisé pour construire les scènes, les ennemis, le menu et la gestion de l'audio.

C#

Langage de programmation des scripts du jeu : comportement des citrouilles ennemies, navigation dans les menus, lecture des sons.

Git et GitHub

Versionnage du code pour travailler à plusieurs et garder l'historique des modifications.
